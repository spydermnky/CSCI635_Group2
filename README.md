## Overview
Image classification is a rapidly expanding problem space in machine learning, with many applications to real-world problems.
The scope of this project is to develop, refine, and test several methods of performing image classification on a dataset of images of cats and dogs. These methods currently include a CNN, with a Random Forest and SVM model both in progress.
